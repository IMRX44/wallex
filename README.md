# پیشرو (Pishro) — ربات معاملاتی هوشمند والکس

ربات خودکار اسپات برای چالش معاملات الگوریتمی والکس (هکاتون Agentic AI استارکوچ).
ربات بازار را به‌صورت زنده تحلیل می‌کند، با منطق **بازگشت پریمیوم (Premium Reversion)** فرصت پیدا می‌کند و با یک **مدل یادگیری ماشین کالیبره** و یک **ایجنت Claude Opus 5.5 با ابزار** تصمیم می‌گیرد. معامله را خودکار روی والکس اجرا می‌کند و برای هر تصمیم دلیلش را ثبت می‌کند.

> مستند فنی کامل برای داوران: **[docs/STRATEGY.md](docs/STRATEGY.md)**
> (معماری، منطق خرید و فروش، نقش AI، مدیریت ریسک، بک‌تست و تست سایه، اجرای مجدد)

## خلاصه در یک نگاه

| بخش | چه می‌کند |
|---|---|
| داده | هر ۲ ثانیه **همه‌ی بازارهای والکس** با یک درخواست، قیمت جهانی **بایننس** (از طریق `binance.vision` که از ایران باز است)، نوبیتکس، و وب‌سوکت عمق والکس |
| قیمت منصفانه | `بایننس <COIN>USDT × تتر/تومان والکس`؛ پریمیوم عادی هر بازار با EWMA یاد گرفته می‌شود |
| ورود | خرید فقط وقتی قیمت والکس به‌اندازه‌ی «لبه»ی کالیبره زیر پریمیوم عادی است؛ سفارش میکر روی بهترین بازارها + خرید فوری (اسنایپر) روی بقیه |
| خروج | فروش در بازگشت به پریمیوم عادی (هرگز زیر سربه‌سر + کارمزد)، حد ضرر، حداکثر زمان نگه‌داری، تبدیل همه به تومان قبل از پایان چالش |
| AI ۱: مدل ML | LightGBM کالیبره‌شده (isotonic)؛ برای **هر سفارش** احتمال سودده بودن بعد از کارمزد را می‌دهد و اندازه‌ی سفارش را تعیین می‌کند؛ با SHAP توضیح می‌دهد |
| AI ۲: ایجنت | Claude Opus 5.5 (از طریق API هوش مصنوعی لیارا) با ۱۱ ابزار: وضعیت را بررسی می‌کند، اخبار را می‌خواند و سیاست معاملاتی را تعیین می‌کند (حالت ریسک، مسدود کردن یا تنظیم هر بازار) |
| ریسک | قوانین سخت بیرون از دسترس AI: افت ۶٪ = توقف و نقد کردن، ضرر روزانه ۲.۵٪، ریسک هر معامله ۰.۸٪، سقف ۲۵٪ در هر بازار، ۲۰٪ نقد همیشه، سقف مشارکت در دفتر سفارش، توقف بعد از ضررهای پیاپی، محافظ داده‌ی کهنه |
| شفافیت | لاگ تصمیم JSONL برای هر سفارش و فیل (سیگنال، احتمال ML، عوامل، سیاست ایجنت)، داشبورد زنده، گزارش بک‌تست HTML |

## اجرای سریع

```bash
pip install -r requirements-dev.txt
cp .env.example .env            # کلیدها را پر کنید (هرگز commit نکنید)

python -m pishro check          # اتصال به والکس/بایننس/نوبیتکس/حساب/مدل AI
python -m pishro fetch          # دانلود ۳۰ روز داده‌ی دقیقه‌ای (از IP ایران)
python -m pishro backtest       # بک‌تست walk-forward + مقایسه با/بدون ML + گزارش + آموزش مدل
PISHRO_MODE=paper python -m pishro serve   # تست سایه با قیمت زنده → http://localhost:8000
PISHRO_MODE=live LIVE_CONFIRM=I_UNDERSTAND python -m pishro serve   # پول واقعی
python -m pishro export         # تحویلی‌ها: لاگ تصمیم‌ها، معاملات، منحنی سرمایه
```

بدون اینترنت هم می‌شود کل مسیر کد را آزمود: `python -m pishro demo` (داده‌ی مصنوعی؛ **فقط برای تست کد، نه ادعای سود**) و `pytest`.

> والکس به IP خارج از ایران جواب نمی‌دهد؛ `fetch`، `check` و اجرای زنده را از ایران یا روی لیارا اجرا کنید.

## دیپلوی روی لیارا

پروژه یک کانتینر Docker است (ربات + داشبورد در یک پروسه) با یک دیسک برای داده:

```bash
npm i -g @liara/cli
export LIARA_API_TOKEN=...  LIARA_TEAM_ID=...   # از کنسول لیارا
APP=pishro-team bash scripts/deploy_liara.sh     # اپ، دیسک، متغیرهای .env و deploy
```

بعد داشبورد روی `https://<APP>.liara.run` در دسترس است.
مدل AI از سرویس هوش مصنوعی لیارا می‌آید: `LLM_BASE_URL=https://ai.liara.ir/api/v1/<id>` و `LLM_MODEL=anthropic/claude-opus-5.5`.

## ساختار کد

```
pishro/
  strategy/reversion.py   منطق مشترک ربات زنده و بک‌تست (پریمیوم، لبه، هدف، گیت‌ها)
  engine/reversion.py     اجرای زنده: سفارش میکر/اسنایپر، خروج، حد ضرر، تشخیص کارمزد
  market/live.py          فید زنده، کندل دقیقه‌ای، گرم شدن با تاریخچه
  ml/                     مدل LightGBM کالیبره، آموزش walk-forward
  ai/                     ایجنت Claude با ابزار، سیاست با سقف‌های سخت، اخبار، روایت معاملات
  risk.py                 مدیر ریسک (همان کلاس در بک‌تست و ربات زنده)
  backtest/               دانلود داده، شبیه‌ساز دقیقه‌ای، گزارش، مونت‌کارلو
  broker/                 بروکر واقعی والکس و بروکر سایه
  web/                    API و داشبورد
  decisions.py            لاگ تصمیم‌ها
video/                    ساخت خودکار ویدئوی دمو از داده‌ی واقعی
```

## امنیت

- کلید API والکس فقط با دسترسی معامله ساخته شود (بدون برداشت).
- هیچ کلیدی در مخزن نیست؛ همه از متغیر محیطی خوانده می‌شوند.
- دکمه‌های کنترلی داشبورد رمز می‌خواهند (`DASHBOARD_PASSWORD`).
